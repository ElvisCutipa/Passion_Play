PASSION PLAY — REEMPLAZAR ARCHIVOS

En tu proyecto existente, dentro de la carpeta passion-play:
- Reemplaza src/App.tsx con el archivo de este paquete.
- Reemplaza src/App.css con el archivo de este paquete.
- Reemplaza src/main.tsx con el archivo de este paquete.
- Reemplaza src/index.css con el archivo de este paquete.
- Reemplaza index.html con el archivo de este paquete.

Después, en la terminal de VS Code (dentro de passion-play), ejecuta:
npm run dev

No se requieren paquetes adicionales de Ionic para esta primera pantalla: es React + CSS responsive. Así evitamos el conflicto de versiones que apareció durante la instalación. La app ya tiene tarjetas, cuatro niveles, puntos demo y modo local/en línea en preparación. El modo online y la persistencia todavía no están implementados.
